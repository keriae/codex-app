## Conversation layout contract

Hidden entries cannot leave empty activity wrappers or flex gaps. Real commentary preserves ordering and separates ordinary tool groups. Standard completed history is collapsed by default; expanded rows retain every actual command. Visible activity units use 16px gaps and group descendants use 4px gaps. Closed bodies are unmounted rather than retaining virtualization estimates as minimum height.

Composer height controls bottom reserve. A view already near the bottom stays attached when footer height changes; a user reading older content keeps their position. Jumping to latest aligns the scroll container's true bottom, including its footer reserve.

## Validation boundary

Current source tests (**1,388 in 182 files**), Node/Web typechecks and production build pass. Native editable-client checks have covered directory/model/backend readiness, real completed history/diffs, local comment controls, terminal behavior, keyboard new chat, actual long-history grouping and the final reply above the composer. Plugin, skill and MCP inventories settled independently in 2.04, 2.13 and 12.67 seconds on the production-out development renderer. Source model-turn tests use synthetic fixtures; local PTY smoke exercises the real installed CLI. Final source-package acceptance also covered Markdown source/preview, find and line-preview cancellation, selection-to-draft, native Save as bytes, folded-file notifications and Settings reentry refresh. Isolated native external-import verification created three durable fixture sessions and validated plugin/MCP/skill configuration without model sampling. See source-validation-current.md. The full-resource reconstruction separately passed a real native model turn and homepage/sidebar/settings/menu/window-zoom checks. These checks do not establish complete original-app interaction or pixel equivalence.
